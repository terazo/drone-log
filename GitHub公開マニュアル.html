ドローン飛行日誌アプリ ／ PC で行う作業

GitHub Pages で公開して iPhone・iPad に入れる

アプリのファイルを GitHub に置いて、iPhone と iPad の Safari から開けるようにする手順です。使うのはブラウザだけで、ソフトのインストールは要りません。公開されるのはアプリの仕組み（プログラム）だけで、飛行記録などのデータは各端末の中にだけ保存されます。

所要時間 20〜30 分 費用 無料 ブラウザ Chrome か Edge
https://ユーザー名.github.io/drone-log/
0 / 6 完了

  1. ファイルを PC に用意する

    約 3 分
    1. drone-log.zip を PC の分かりやすい場所（デスクトップなど）に置く
    2. zip を右クリック → すべて展開
    3. できた drone-log フォルダを開き、次のようになっているか確認する
    drone-log/ ├─ index.html ← これが一番上の階層にあること ├─ app.js / db.js / training.js / guides.js / checklists.js ├─ styles.css / sw.js / manifest.webmanifest ├─ icons/ （フォルダ） ├─ vendor/leaflet/ （フォルダ） └─ はじめに.md （説明書。アップロードしても問題ありません）

  2. GitHub のアカウントを作る

    約 5 分
    1. ブラウザで github.com/signup を開く
    2. メールアドレス、パスワード、ユーザー名を入力する
    3. メールに届いた確認コードを入力する
    4. 「2 段階認証」の設定を求められたら、画面の案内に従う（スマホの認証アプリか SMS を使います）
    ユーザー名のコツアプリの URL の一部になります。英小文字・数字・ハイフンだけにすると、iPhone で入力しやすくなります。

  3. 置き場所（リポジトリ）を作る

    約 2 分
    1. ログイン後、右上の ＋ → New repository
    2. Repository name に drone-log と入力する
    3. Public を選ぶ（ほかの項目はそのままで大丈夫です）
    4. 下の Create repository を押す
    Public で大丈夫な理由無料で公開するには Public が必要です。誰でも見られるのはアプリのプログラムだけで、あなたの飛行記録・機体・技能証明などのデータは含まれません。

  4. ファイルをアップロードする

    約 3 分
    1. リポジトリの画面にある青い文字の uploading an existing file を押す
    2. エクスプローラーで drone-log フォルダを開いて、中身を Ctrl＋A ですべて選ぶ
    3. 選んだものをブラウザの画面にドラッグ＆ドロップする
    4. 一覧にファイルが並んだら、下の Commit changes を押す
    5. リポジトリのトップに index.html、icons、vendor が並んでいれば完了
    フォルダそのものではなく「中身」をドロップdrone-log フォルダごとドロップすると、index.html が一段下に入ってしまい、アプリが開きません。
    icons・vendor が上がらなかったときもう一度 Add file → Upload files を開き、icons と vendor をフォルダごとドラッグしてください。

  5. 公開する（GitHub Pages）

    約 5 分
    1. リポジトリの上にある Settings を押す
    2. 左のメニューの Pages を押す
    3. Source を Deploy from a branch にする
    4. Branch を main と / (root) にして Save
    5. 1〜3 分待ってから再読み込みし、「Your site is live at …」と表示されたら公開完了
    6. 表示された URL（https://ユーザー名.github.io/drone-log/）を PC のブラウザで開き、アプリが表示されるか確認する

  6. iPhone・iPad のホーム画面に追加する

    約 2 分
    1. URL を自分宛てにメールや LINE で送り、iPhone の Safari で開く
    2. 画面下の共有ボタン（四角から上向きの矢印）→ ホーム画面に追加 → 追加
    3. 以後はホーム画面のアイコンから開く（Safari で開いた場合とはデータの保存場所が別になります）
    4. iPad でも同じ操作をする
    iPhone と iPad のデータをそろえるにはアプリの ⚙ →「共有用に書き出す」→ AirDrop で相手に送り、相手の端末で ⚙ →「取り込む（統合）」を選びます。

アプリを新しい版に更新するとき

  1. 新しい drone-log.zip を展開する
  2. GitHub のリポジトリで Add file → Upload files
  3. フォルダの中身をすべてドラッグ＆ドロップ → Commit changes（同じ名前のファイルは自動で上書きされます）
  4. 2〜3 分待つ
  5. iPhone・iPad のアプリで ⚙ → 最新版に更新

データは更新しても消えません。念のため、更新前に ⚙ →「バックアップを書き出す」をしておくと安心です。

うまくいかないとき

URL を開くと「404」と表示される

公開の反映に数分かかることがあります。3〜5 分待ってから再読み込みしてください。

それでも直らない場合は、リポジトリのトップに index.html があるか確認してください。drone-log/index.html のように一段下に入っていたら、ステップ 4 をやり直します。

Settings に Pages が見つからない

リポジトリの画面（github.com/ユーザー名/drone-log）の上のメニューにある Settings を開いているか確認してください。右上のアイコンから開く「アカウントの Settings」とは別の画面です。

画面は出るが、地図やアイコンが表示されない

icons と vendor フォルダが上がっていない可能性があります。リポジトリのトップにこの 2 つのフォルダがあるか確認し、なければステップ 4 の「icons・vendor が上がらなかったとき」を行ってください。

iPhone で「ホーム画面に追加」が出てこない

Safari で開いているか確認してください。LINE やメールのアプリ内のブラウザで開いた場合は、右下などにある「Safari で開く」を選んでから操作します。

更新したのに新しい機能が出てこない

アプリの ⚙ →「最新版に更新」を押してください。それでも変わらない場合は、アプリを一度閉じて（ホーム画面から上にスワイプして終了）開き直します。

GitHub の画面の表示や言葉は、変更されることがあります。ボタンの名前が少し違う場合は、近い名前のものを探してください。
